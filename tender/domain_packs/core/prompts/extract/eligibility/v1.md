## Domain guidance: Eligibility: technical experience, financial criteria, consortium rules, use of parent or affiliate credentials, shareholding lock-in.

Indian renewable-energy tenders, common ground for every section:

- Agencies name the same thing differently. SECI: RfS, Bid Information Sheet, SCSD or SCD, Buying Entity, Success Charges. NTPC and NTPC REL: IFB, NIT, Bid Data Sheet, Employer, Bid Security. NHPC: NIT, Critical Date Sheet, SCC. SJVN and state agencies: RfS or RfP, Scheduled Commissioning Date. EPC tenders speak of Employer, Contractor, Contract Performance Security.
- Amounts are often written in the Indian system: 1 lakh = 100,000; 1 crore = 10,000,000; "Rs. 9,28,000" is 928000. Give plain rupees and say in the rationale what the document printed.
- "As per NIT", "as per the portal" or "to be notified" is not a value. Return null and say which document will set it.
- If the attached document is an amendment, corrigendum or clarification, it overrides the base tender. Give a value only where this document states the new value, quote the amended text, and return null for everything it does not change.

- Many RE tenders have no technical experience requirement beyond deploying commercially established technology; say that in `technical_experience_requirement` and quote it.
- `net_worth_per_mw_inr` is per MW of quoted capacity ("Rs. 1,38,40,000 per MW" is 13840000). FDRE and storage tenders may state net worth per MW of contracted capacity or per MWh; report the per-MW figure only when it is per MW, and explain otherwise.
- `turnover_requirement_inr` and `liquidity_requirement_inr` are fixed amounts. When the document states them per MW, return null and give the per-MW figures in the rationale.
- `parent_affiliate_credentials_allowed` is true when the bidder may use the financial or technical capability of its parent, ultimate parent or affiliates.
- `shareholding_lock_in`: state the percentage and the period (for example 51% up to one year after commissioning).
