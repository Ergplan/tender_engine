## Domain guidance: Key dates and periods: issue, pre-bid, queries, bid deadline, opening, e-RA, validity, award, PPA signing, financial closure, commissioning, tenure.

Indian renewable-energy tenders, common ground for every section:

- Agencies name the same thing differently. SECI: RfS, Bid Information Sheet, SCSD or SCD, Buying Entity, Success Charges. NTPC and NTPC REL: IFB, NIT, Bid Data Sheet, Employer, Bid Security. NHPC: NIT, Critical Date Sheet, SCC. SJVN and state agencies: RfS or RfP, Scheduled Commissioning Date. EPC tenders speak of Employer, Contractor, Contract Performance Security.
- Amounts are often written in the Indian system: 1 lakh = 100,000; 1 crore = 10,000,000; "Rs. 9,28,000" is 928000. Give plain rupees and say in the rationale what the document printed.
- "As per NIT", "as per the portal" or "to be notified" is not a value. Return null and say which document will set it.
- If the attached document is an amendment, corrigendum or clarification, it overrides the base tender. Give a value only where this document states the new value, quote the amended text, and return null for everything it does not change.

- Dates are day-first (05.06.2026 is 5 June 2026). Give a date only if the pages print it for this tender. Dates inside examples ("for e.g.", "illustration") are not tender dates.
- `bid_submission_deadline` is the closing date for online submission. When a later date is given for hard copies, mention it in the rationale.
- When the document defers dates ("as per NIT on ISN-ETS portal", "will be notified"), leave each such date null and fill `dates_deferred_note` with which dates are deferred and to which document or notice, quoting the deferral.
- `scod_months` and `scod_reference` go together: "months from the Effective Date of the PPA" is effective_date; "from the date of signing of PPA" is ppa_signing; "from issuance of LoA" is loa. These are different references; do not convert one into another.
- `financial_closure_months`: say in the rationale which date it is counted from. If the document states financial closure as a number of months before the scheduled commissioning date, return null and say so.
- `bid_validity_days`: convert months to days only when the document itself gives days; otherwise report the number of days printed.
