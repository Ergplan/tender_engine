## Domain guidance: Commercial terms: ceiling tariff, tariff structure, payment security, change in law, deemed generation, late payment surcharge, termination compensation, offtaker.

Indian renewable-energy tenders, common ground for every section:

- Agencies name the same thing differently. SECI: RfS, Bid Information Sheet, SCSD or SCD, Buying Entity, Success Charges. NTPC and NTPC REL: IFB, NIT, Bid Data Sheet, Employer, Bid Security. NHPC: NIT, Critical Date Sheet, SCC. SJVN and state agencies: RfS or RfP, Scheduled Commissioning Date. EPC tenders speak of Employer, Contractor, Contract Performance Security.
- Amounts are often written in the Indian system: 1 lakh = 100,000; 1 crore = 10,000,000; "Rs. 9,28,000" is 928000. Give plain rupees and say in the rationale what the document printed.
- "As per NIT", "as per the portal" or "to be notified" is not a value. Return null and say which document will set it.
- If the attached document is an amendment, corrigendum or clarification, it overrides the base tender. Give a value only where this document states the new value, quote the amended text, and return null for everything it does not change.

- `tariff_ceiling_inr_per_kwh` only when the tender prints a ceiling or maximum tariff. Trading margin, payment security charges and penalty multipliers are not a ceiling.
- `tariff_structure`: fixed for a single tariff for the whole term; escalating when it rises by a stated rate; two_part for separate fixed and variable charges; capacity_charge when payment is per MW per month (storage and capacity contracts).
- `offtaker`: the entity that finally buys the power. For SECI, NTPC and NHPC tenders the agency is an intermediary procurer and sells to Buying Entities (discoms); say both in the value, intermediary first.
- For the long-text clauses give a faithful summary of two or three sentences with the numbers that matter (letter of credit size, surcharge rate, compensation formula), and quote the governing clause. The draft PPA, where attached, governs over the RfS summary; report a disagreement in the rationale.
- An EPC or supply tender has no tariff; return null for tariff fields and report terms of payment security only if the pages state them.
