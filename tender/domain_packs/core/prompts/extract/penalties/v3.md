## Domain guidance: Penalties: liquidated damages for delay, extension limits, shortfall penalties, PBG encashment, termination for delay.

Indian renewable-energy tenders, common ground for every section:

- Agencies name the same thing differently. SECI: RfS, Bid Information Sheet, SCSD or SCD, Buying Entity, Success Charges. NTPC and NTPC REL: IFB, NIT, Bid Data Sheet, Employer, Bid Security. NHPC: NIT, Critical Date Sheet, SCC. SJVN and state agencies: RfS or RfP, Scheduled Commissioning Date. EPC tenders speak of Employer, Contractor, Contract Performance Security.
- Amounts are often written in the Indian system: 1 lakh = 100,000; 1 crore = 10,000,000; "Rs. 9,28,000" is 928000. Give plain rupees and say in the rationale what the document printed.
- "As per NIT", "as per the portal" or "to be notified" is not a value. Return null and say which document will set it.
- If the attached document is an amendment, corrigendum or clarification, it overrides the base tender. Give a value only where this document states the new value, quote the amended text, and return null for everything it does not change.

- `delay_ld_per_mw_per_day_inr` only when the document states an amount per MW per day. SECI-style tenders encash the PBG on a per-day basis proportionate to the capacity not commissioned; that is not a per-MW-per-day figure: return null and describe it in `pbg_encashment_triggers`.
- `max_scod_extension_months` is the longest delay beyond the scheduled date that is allowed with penalties; `termination_delay_months` is the delay after which the agreement may be terminated or capacity reduced. They are often the same clause; quote it for both.
- `shortfall_penalty_basis`: how a shortfall in energy, availability or performance is charged (for example 1.5 times the PPA tariff for the shortfall).

Structured fields (`*_structured`, `shortfall_rules`, `cuf_terms`) hold the numbers of the prose field beside them, for a financial model. A wrong number here is worse than a missing one.

- **A number is given only if the document prints that number in a passage you quote for this field.** Printed means in figures ("1.5", "10%", "Rs. 9,28,000") or written out as a number ("one and a half times", "24 (twenty-four) months"). Give it as printed, converted only to the key's unit (lakh and crore to rupees, paise to rupees, a printed percentage to a multiple where the key is a multiple).
- **Never compute a number.** Do not subtract from 100, add, multiply, or turn one figure into another. "Shortfall is permissible up to 10% below the requirement" prints a tolerance of 10; it does not print a threshold of 90, so no threshold is given.
- **Words that are not a number never become a number.** "At the tariff", "at the applicable tariff", "in full", "the entire amount", "without limit" state how something is computed, not a figure. Where the record has a key that takes a fixed choice for this, give that choice; otherwise leave the numeric key out. Do not write 100 for "in full" or "at the tariff". Keep the document's wording in the prose field beside the record, which is where a reader looks for it.
- Give a key only when these pages state it. A key the pages do not state is left out; never write 0, never fill a key from what is usual in such tenders.
- When the pages state none of the keys, the value is null.
- The prose field and the structured field must say the same thing.
- **Before you answer, check every number of every structured value against the quotes of that same field.** For each number, either a quote of this field prints it, or you add the passage that prints it to this field's quotes, or you remove the number. A quote given for another field does not count.

- `delay_ld_structured`: `basis` pbg_encashment_per_day when delay is charged by encashing the PBG day by day, with `pbg_encashed_over_months` the months over which it is fully encashed; pct_of_contract_price_per_week with `pct_per_week` and `cap_pct_of_contract_price` for works contracts; inr_per_mw_per_day with the rate, which must equal `delay_ld_per_mw_per_day_inr`.
- `shortfall_rules`: one item per rule. `threshold_pct` is the level below which the penalty applies, and only when the pages print that level (90 for "not less than 90% of the declared value"; 85 for "energy corresponding to 85% of the declared CUF"); `threshold_of` what it is a share of. `tolerance_pct` is the permitted shortfall, when the pages print that instead (10 for "shortfall permissible up to 10% below the requirement"). Give whichever the pages print; when they print only one, leave the other out and do not derive it. Quote the passage that prints each. `penalty_multiple_of_tariff` is 1.5 for "1.5 x PPA Tariff" or "one and a half times the tariff"; a printed percentage of the tariff is the same figure in another unit (0.5 for "50% of the tariff"). A penalty "at the tariff" with no figure printed has no multiple: leave it out. `default_after_years` and `default_damages_months_of_tariff` when continued shortfall is an event of default.
