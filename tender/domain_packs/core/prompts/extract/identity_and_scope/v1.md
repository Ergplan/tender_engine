## Domain guidance: Identity and scope fields of a tender: number, agency, title, mode, capacity, bid limits, location, delivery and metering points.

Indian renewable-energy tenders, common ground for every section:

- Agencies name the same thing differently. SECI: RfS, Bid Information Sheet, SCSD or SCD, Buying Entity, Success Charges. NTPC and NTPC REL: IFB, NIT, Bid Data Sheet, Employer, Bid Security. NHPC: NIT, Critical Date Sheet, SCC. SJVN and state agencies: RfS or RfP, Scheduled Commissioning Date. EPC tenders speak of Employer, Contractor, Contract Performance Security.
- Amounts are often written in the Indian system: 1 lakh = 100,000; 1 crore = 10,000,000; "Rs. 9,28,000" is 928000. Give plain rupees and say in the rationale what the document printed.
- "As per NIT", "as per the portal" or "to be notified" is not a value. Return null and say which document will set it.
- If the attached document is an amendment, corrigendum or clarification, it overrides the base tender. Give a value only where this document states the new value, quote the amended text, and return null for everything it does not change.

- `tender_number` is the reference printed on the cover or in the Bid Information Sheet (for example "SECI/C&P/IPP/13/0006/26-27", "NRE-CS-5924-003"), not an e-portal event id unless that is the only reference printed.
- `total_capacity_mw` is the aggregate tendered capacity. A peak-supply tender written as "4800 MWh (1200 MW x 4 Hrs)" has total_capacity_mw 1200 and total_capacity_mwh 4800. Standalone storage written as "2000 MW / 4000 MWh" has both. Do not compute one from the other; null when the document gives only one.
- `min_bid_mw` and `max_bid_mw` are the limits for one bidder including its affiliates, usually in the clause on capacity allocation or in the Bid Information Sheet.
- `location_constraint`: ists_anywhere when projects may be anywhere in India with ISTS connectivity; state_specific when a state is required; named_substation when a substation is named; named_site when the site or park is given.
- `procurement_mode`: SECI and NHPC RfS documents are normally single stage, two envelope, followed by an e-reverse auction: report e_reverse_auction when an e-RA is part of the process, otherwise the envelope structure.
