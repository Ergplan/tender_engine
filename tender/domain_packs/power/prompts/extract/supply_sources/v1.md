## Domain guidance: Supply sources: which sources may, must or must not supply the contracted power, with their limits, and the conditions on storage.

Indian renewable-energy tenders, common ground for every section:

- Agencies name the same thing differently. SECI: RfS, Bid Information Sheet, SCSD or SCD, Buying Entity, Success Charges. NTPC and NTPC REL: IFB, NIT, Bid Data Sheet, Employer, Bid Security. NHPC: NIT, Critical Date Sheet, SCC. SJVN and state agencies: RfS or RfP, Scheduled Commissioning Date. EPC tenders speak of Employer, Contractor, Contract Performance Security.
- Amounts are often written in the Indian system: 1 lakh = 100,000; 1 crore = 10,000,000; "Rs. 9,28,000" is 928000. Give plain rupees and say in the rationale what the document printed.
- "As per NIT", "as per the portal" or "to be notified" is not a value. Return null and say which document will set it.
- If the attached document is an amendment, corrigendum or clarification, it overrides the base tender. Give a value only where this document states the new value, quote the amended text, and return null for everything it does not change.

- `source_mix_rules`: one item per source the pages state a rule for, each with its own quote. Name a source (`thermal`, `market_purchase`, `bess`, ...) only when the pages name it; a clause that allows "any source", "non-RE sources" or "alternate sources" in general is one item with source `any_non_re`, never several items for sources the clause does not name. `treatment`: `required` when the source must be part of the supply (a mandatory storage system, a solar capacity that must be installed); `prohibited` when it is excluded; `allowed_with_limit` when a number limits it, with `limit_value` and `limit_unit` as the pages print them (a minimum RE share of 51% is not a 49% limit on another source: give the RE share under the field that holds it and put the balance clause under `any_non_re` without a number unless the pages print one); `allowed` otherwise. `condition` quotes the condition in a few words (charged from RE only, co-located, through a trader). A tender that says nothing about sources of supply (an EPC works contract, a transmission licence) has no items: return an empty list and say so in the rationale.
- A definition ("Traceable Green Power means supply from solar, wind, hydro, biomass, including through storage") is a rule for those sources only where the pages make the defined term an obligation; then each named source is one `allowed` item quoting the definition and the obligation.
- `bess_charging_rule`: only when the pages condition storage; `regulation_reference` as printed (for example "CERC Sharing Regulations").
