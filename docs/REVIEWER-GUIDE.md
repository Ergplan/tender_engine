# Reviewer guide

One page for the person reviewing a tender. The same text is in the "How to review" panel at the top of the review screen.

## What this review is for

The values you approve here become the canonical record of this tender and the benchmark the extraction is measured against. Nothing is published until you have approved it.

You open the review from the link you were sent. The link is yours: your name is on every decision made with it. Each decision is saved the moment you make it, so you can close the page and come back.

## How to decide a field

1. Read the value, click an evidence chip, and confirm the quoted words on the page.
2. Approve if the value is what the document says.
3. Edit if the value is wrong or incomplete, and give the page and the words that state it.
4. Not in document if the tender genuinely does not state it. That is a correct answer, not a gap.
5. Flag if you are unsure, and move on. A flagged field is not counted as decided.

The summary at the top is written from the fields below it, not read from the document a second time. Each of its sentences carries the evidence of the fields it draws on, so a number after a sentence opens the same passage as the chip of that field. If a value in the summary is wrong, the field it comes from is wrong: correct the field. Point at a number to see which field it comes from and the words it quotes; click it to see the passage.

Because the summary is written from the fields, you decide it last. Its buttons stay off until every other field has a decision. If you corrected a field or marked one as not in the document, the summary is then written again from your decisions, which takes about a minute, and the card offers the new text. If you change a field after approving the summary, that approval is withdrawn and the summary is written again. The note above the summary says what it leaves out.

When a field has several evidence chips they are numbered. In the summary, each sentence ends with the number of the chip that supports it; in other fields, the focused field lists the words each chip quotes. The passage of the chip you clicked is the one highlighted in the document; the others are drawn faintly.

A field that comes from an amendment carries a tag such as "v2 amendment" and shows what the earlier version said. If the amendment does not in fact change the field, mark it Not in document: the earlier version's value comes back for you to decide.

Complete review becomes available once every required field (marked with a red star) has a decision. After completing, the review can be read but no longer changed.

## What the confidence figure means

It is the model's own confidence in its reading, not a measure of whether the value is correct. A low figure often means the document states the field ambiguously or only in part, not that the value is likely wrong.

Example: a tender number at 60% can be right when the document prints only a portal Tender ID and leaves "RfS No." blank.

Read the rationale under the value before treating a low figure as an error.

A section header says how many of its undecided fields need a closer look: fields a validation rule flagged, and fields with low model confidence. They are a good place to start.

## Keys

| Key | What it does |
| --- | --- |
| Enter | approve and go to the next undecided field |
| E | edit |
| N | not in document |
| F | flag |
| J / K | next / previous field |
| Esc | cancel |

Keys do nothing while you are typing in a box, except Esc.
